# 🪄전개지시M

실리태번(SillyTavern)용 전개지시({{direction}}) 관리 확장입니다.

## 주요 기능
- 전역(Global) / 캐릭터(Character) / 줄거리(Plot) / 채팅(Chat) 탭을 **개별로 저장하고, 켜져 있는 범위 전부를 동시에** 프롬프트에 반영
  - 합쳐질 때 `[Format Rules]`(전역) / `[Character Notes]`(캐릭터) / `[Story Direction]`·`[Next Beats]`(줄거리) / `[Director's Note]`(채팅) 라벨이 붙습니다.
- **줄거리 탭**은 위아래 두 칸입니다. **큰 줄거리**(전체 방향·결말, 배경으로만 참고)와 **지금 전개**(앞으로 몇 챗 분량의 구체 사건, 한 응답에 한 장면씩)가 각각 다른 프롬프트·Depth로 들어갑니다. 켜기/끄기는 두 칸이 함께 움직이고, ←/→·지우개는 지금 편집 중인(강조된) 칸에 적용됩니다.
- 범위별로 분리된 프리셋 라이브러리 (전역용 프리셋 / 캐릭터용 프리셋, 채팅 범위는 프리셋을 쓰지 않고 그 공간만큼 입력칸이 더 큽니다)
- 컴팩트 팝업에서 범위 전환, 이전/현재 내용 토글(←/→), 프리셋 저장·이름변경·삭제 지원 (토글·지우개 버튼은 팝업 맨 아래 오른쪽에 있습니다)

## 설치 방법
1. 이 저장소 파일을 실리태번 경로의 아래 폴더에 복사합니다.
   - `public/scripts/extensions/third-party/Direction-Manager-DB/`
   - (실리태번 확장 설치 기능으로 `https://github.com/DenBzs/Direction-Manager-DB` 를 그대로 설치해도 폴더명이 자동으로 맞춰집니다.)
2. 실리태번을 새로고침합니다.
3. 확장 설정의 **🪄전개지시M** 패널에서 활성화/프롬프트/범위별 Depth를 설정합니다. 팝업을 열 때는 항상 마지막으로 봤던 범위 탭이 그대로 복원됩니다.

## 범위(Scope) 적용 방식
활성화되어 있고 내용이 있는 범위를 **전부** 모아서 각각 라벨을 붙여 프롬프트에 주입합니다.

- **전역**: 본문 길이, 출력 언어, 규칙 등 계속 적용될 내용 (`[Format Rules]`)
- **캐릭터**: 지금 열려 있는 채팅방에서 이어지는 상황·감정·성격·세계관 메모. 모델이 배경으로만 알고 있고 글에는 직접 드러내지 않습니다 (`[Character Notes]`)
- **줄거리 · 큰 줄거리**: 전체 방향과 결말. 서두르지도 정체되지도 않게 천천히 향해 갑니다 (`[Story Direction]`)
- **줄거리 · 지금 전개**: 앞으로 일어날 구체적인 사건을 순서대로. 이미 쓴 부분은 건너뛰고 한 응답에 한 장면(또는 일부)만 진행합니다 (`[Next Beats]`)
- **채팅**: 다음 챗에 바로 반영할 내용, 예: 사칭용 인풋 (`[Director's Note]`)

다섯 프롬프트는 각각 **다른 Depth(삽입 위치)**로 들어가며, 확장 설정 패널에서 따로 조절합니다. 기본값은 채팅 0 / 지금 전개 1 / 전역 2 / 큰 줄거리 3 / 캐릭터 5 입니다. 모든 Depth는 원래 채팅 메시지 기준으로 계산되므로 서로 값이 달라도 의도한 위치에 들어갑니다.

> 줄거리 두 칸도 캐릭터·채팅과 마찬가지로 **지금 열려 있는 채팅방 단위**로 저장됩니다.

> ⚠️ **캐릭터 범위는 "그 캐릭터 전체"가 아니라, 채팅 범위와 마찬가지로 지금 열려 있는 채팅방(대화) 안에서만 적용됩니다.**
> 같은 캐릭터라도 채팅방이 다르면 캐릭터 범위 내용도 서로 분리되어 저장됩니다.

## 프리셋 사용법
- 프리셋 드롭다운: **현재 선택된 범위**(전역/캐릭터) 전용 목록만 표시 (채팅·줄거리 탭에는 프리셋 줄이 표시되지 않습니다)
- 💾: 현재 textarea 내용을 이름과 함께 해당 범위에 저장
- ✏️: 선택한 프리셋 이름 변경
- ❌: 선택한 프리셋 삭제

## 이전/현재 내용 토글 (←/→)
범위별로 "직전에 저장돼 있던 내용"을 한 칸 기억합니다. 팝업 맨 아래 오른쪽의 ←/→ 버튼을 누르면
지금 내용과 직전 내용이 서로 맞바뀝니다. 바로 옆의 지우개 버튼으로 지운 내용도 이 버튼으로 복원할 수 있습니다.

## 데이터 저장 위치
- `extension_settings["Direction-Manager-DB"]` 하위에 `global / chars / chats / presets` 구조로 저장됩니다.
- 줄거리 두 칸은 `plotMains / plotNexts` 아래에 채팅 단위로 저장됩니다.
- 캐릭터 카드 자체에는 아무것도 쓰지 않습니다(오직 `extension_settings`).
- 설정 패널(`settings.html`)은 이 확장이 실제로 설치된 폴더에서 읽습니다. 폴더명이 `Direction-Manager-DB`가 아니어도 됩니다.

## 업데이트 시 참고 (v1.2)
- 캐릭터 프롬프트가 예전 기본값 그대로였다면 "은은하게 참고" 버전으로 자동 교체됩니다. 직접 고친 프롬프트는 그대로 둡니다.
- 삽입 Depth가 예전 기본값(전부 1)이었다면 위 새 기본값으로 바뀝니다. 직접 바꾼 값은 그대로 둡니다.
- 기본값으로 되돌리려면 설정 패널의 "기본값으로 초기화"를 누르세요 (프롬프트도 함께 초기화됩니다).
