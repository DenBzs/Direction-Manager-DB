# 🪄전개지시M

실리태번(SillyTavern)용 전개지시({{direction}}) 관리 확장입니다.

## 주요 기능
- 전역(Global) / 캐릭터(Character) / 채팅(Chat) 세 범위를 **개별로 저장하고, 켜져 있는 범위 전부를 동시에** 프롬프트에 반영
  - 합쳐질 때 `[Format Rules]`(전역) / `[Character Notes]`(캐릭터) / `[Director's Note]`(채팅) 라벨이 붙습니다.
- 범위별로 분리된 프리셋 라이브러리 (전역용 프리셋 / 캐릭터용 프리셋 / 채팅용 프리셋 따로 관리)
- 컴팩트 팝업에서 범위 전환, 이전/현재 내용 토글(←/→), 프리셋 저장·이름변경·삭제 지원
- 기존 v1/v2 설정 자동 마이그레이션

## 설치 방법
1. 이 저장소 파일을 실리태번 경로의 아래 폴더에 복사합니다.
   - `public/scripts/extensions/third-party/Direction-Manager-DB/`
   - (실리태번 확장 설치 기능으로 `https://github.com/DenBzs/Direction-Manager-DB` 를 그대로 설치해도 폴더명이 자동으로 맞춰집니다.)
2. 실리태번을 새로고침합니다.
3. 확장 설정의 **🪄전개지시M** 패널에서 활성화/프롬프트/Depth/팝업 기본 범위를 설정합니다.

## 범위(Scope) 적용 방식
과거 버전(v2 이전)은 Chat > Character > Global 순으로 **하나만** 적용되는 폴백 구조였지만,
지금은 활성화되어 있고 내용이 있는 범위를 **전부** 모아서 각각 라벨을 붙여 합칩니다.
예) 전역+채팅만 켜져 있으면 `[Format Rules] ... \n\n [Director's Note] ...` 형태로 주입됩니다.

## 프리셋 사용법
- 프리셋 드롭다운: **현재 선택된 범위**(전역/캐릭터/채팅) 전용 목록만 표시
- 💾: 현재 textarea 내용을 이름과 함께 해당 범위에 저장
- ✏️: 선택한 프리셋 이름 변경
- ❌: 선택한 프리셋 삭제

## 이전/현재 내용 토글 (←/→)
범위별로 "직전에 저장돼 있던 내용"을 한 칸 기억합니다. 범위 줄 우측의 ←/→ 버튼을 누르면
지금 내용과 직전 내용이 서로 맞바뀝니다. 지우개 버튼으로 지운 내용도 이 버튼으로 복원할 수 있습니다.

## 데이터 저장 위치
- `extension_settings["Direction-Manager-DB"]` 하위에 `global / chars / chats / presets` 구조로 저장됩니다.
- 캐릭터 카드 자체에는 아무것도 쓰지 않습니다(오직 `extension_settings`).

## 수동 테스트 체크리스트
1. 전역/캐릭터/채팅 세 범위를 모두 켠 뒤, 프롬프트에 세 블록이 라벨과 함께 전부 포함되는지 확인
2. 캐릭터 A의 채팅 범위 값과 캐릭터 B의 채팅 범위 값이 서로 섞이지 않는지 확인
3. 범위별 프리셋 저장/로드/삭제/이름변경이 해당 범위에만 적용되는지 확인
4. 지우개로 지운 뒤 ←/→ 버튼으로 복원되는지 확인
5. 콘솔에서 `extension_settings["Direction-Manager-DB"]` 구조 확인
