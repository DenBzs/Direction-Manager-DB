# 🪄전개지시M

실리태번(SillyTavern)용 전개지시({{direction}}) 관리 확장입니다.

## 주요 기능
- 규칙 / AU / 캐릭터 / 줄거리 / 채팅 탭을 **개별로 저장하고, 켜져 있는 범위 전부를 동시에** 프롬프트에 반영
  - 합쳐질 때 `[Format Rules]`(규칙) / `[World Setting]`(AU) / `[Character Notes]`(캐릭터) / `[Story Direction]`·`[Next Beats]`(줄거리) / `[Director's Note]`(채팅) 라벨이 붙습니다.
- **프리셋은 규칙·AU 탭에만 있고, 여러 개를 동시에 켤 수 있습니다.** 켜 둔 프리셋은 목록 순서대로 이어 붙어서 들어갑니다. 캐릭터·줄거리·채팅 탭은 프리셋 없이 그 공간만큼 입력칸이 더 큽니다.
- **줄거리 탭**은 위아래 두 칸입니다. **큰 줄거리**(전체 방향·결말, 배경으로만 참고)와 **작은 줄거리**(앞으로 몇 챗 분량의 구체 사건, 한 응답에 한 장면씩)가 각각 다른 프롬프트·Depth로 들어갑니다. 켜기/끄기는 두 칸이 함께 움직이고, ←/→·지우개는 지금 편집 중인(강조된) 칸에 적용됩니다.
- 컴팩트 팝업에서 범위 전환, 이전/현재 내용 토글(←/→), 프리셋 저장·이름변경·삭제 지원 (토글·지우개 버튼은 팝업 맨 아래 오른쪽에 있습니다)

## 설치 방법
1. 이 저장소 파일을 실리태번 경로의 아래 폴더에 복사합니다.
   - `public/scripts/extensions/third-party/Direction-Manager-DB/`
   - (실리태번 확장 설치 기능으로 `https://github.com/DenBzs/Direction-Manager-DB` 를 그대로 설치해도 폴더명이 자동으로 맞춰집니다.)
2. 실리태번을 새로고침합니다.
3. 확장 설정의 **🪄전개지시M** 패널에서 활성화/프롬프트/범위별 Depth를 설정합니다. 팝업을 열 때는 항상 마지막으로 봤던 범위 탭이 그대로 복원됩니다.

## 범위(Scope) 적용 방식
활성화되어 있고 내용이 있는 범위를 **전부** 모아서 각각 라벨을 붙여 프롬프트에 주입합니다. 안 쓰는 탭은 팝업 맨 위의 체크 표시를 꺼 두면 프롬프트에 들어가지 않습니다.

- **규칙**: 검열 방지 문구, 사용 유의 단어, 언어 설정과 글자수 설정 등 계속 적용될 내용 (`[Format Rules]`)
- **AU**: 오메가버스·센티넬버스 같은 세계관 설정. 여러 개를 동시에 켜면 하나로 합쳐진 세계로 받아들입니다 (`[World Setting]`)
- **캐릭터**: 지금 열려 있는 채팅방의 상황·감정·성격 등 메모. 모델이 배경으로만 알고 있고 글에는 직접 드러내지 않습니다 (`[Character Notes]`)
- **줄거리 · 큰 줄거리**: 전체 방향과 결말. 서두르지도 정체되지도 않게 천천히 향해 갑니다 (`[Story Direction]`)
- **줄거리 · 작은 줄거리**: 앞으로 일어날 구체적인 사건을 순서대로. 이미 쓴 부분은 건너뛰고 한 응답에 한 장면(또는 일부)만 진행합니다 (`[Next Beats]`)
- **채팅**: 다음 챗에 바로 반영할 내용, 예: 사칭용 인풋 (`[Director's Note]`)

여섯 프롬프트는 각각 **다른 Depth(삽입 위치)**로 들어가며, 확장 설정 패널에서 따로 조절합니다. 기본값은 규칙 0 / 채팅 1 / AU 2 / 캐릭터 2 / 작은 줄거리 3 / 큰 줄거리 4 입니다. 숫자가 작을수록 최신 메시지에 가깝게 들어가 더 강하게 작용합니다. 모든 Depth는 원래 채팅 메시지 기준으로 계산되므로 서로 값이 달라도 의도한 위치에 들어갑니다.

> 캐릭터·줄거리 두 칸·채팅은 **지금 열려 있는 채팅방 단위**로 저장됩니다.

> ⚠️ **캐릭터 범위는 "그 캐릭터 전체"가 아니라, 채팅 범위와 마찬가지로 지금 열려 있는 채팅방(대화) 안에서만 적용됩니다.**
> 같은 캐릭터라도 채팅방이 다르면 캐릭터 범위 내용도 서로 분리되어 저장됩니다.

## 프리셋 사용법 (규칙 · AU 탭)

- 프리셋 목록과 내용은 **모든 채팅방이 공유**합니다. 대신 **어떤 프리셋을 켜 뒀는지, 어떤 프리셋을 열어뒀는지는 채팅방마다 따로** 기억합니다.
- 프리셋 이름 칸을 누르면 목록이 열립니다. 줄마다 `🟢 이름 · ★` 가 있습니다.
  - **🟢(초록불)**: 누르면 켜기/끄기. 켜진 프리셋만 프롬프트에 들어가고, **여러 개를 동시에** 켤 수 있습니다. 켜진 프리셋은 목록 순서대로 이어 붙습니다.
  - **이름(굵은 글씨)**: 줄을 누르면 그 프리셋이 **현재 프리셋**이 되어 아래 입력칸에서 보고 고칠 수 있습니다. 현재 프리셋은 굵게 표시됩니다. 현재 프리셋을 켜 둔 경우, 저장 전에 고친 내용이 그대로 프롬프트에 반영됩니다.
  - **★**: 아직 한 번도 건드리지 않은 새 채팅방에서 처음부터 켜져 있을 프리셋입니다. 여러 개를 지정할 수 있습니다.
- 목록 위쪽 **↕ 순서 편집**을 누르면 줄마다 ▲▼🗑가 생겨, 순서를 바꾸거나 바로 삭제할 수 있습니다. 순서는 프롬프트에 들어가는 순서이기도 합니다. 삭제는 확인창을 한 번 거칩니다.
- 버튼은 `💾 저장 · ＋ 새 프리셋 · ✏️ 이름 변경 · 🗑 삭제` 순서입니다. 새 프리셋을 만들면 바로 켜진 상태가 됩니다.
- 현재 프리셋 내용을 고치면 **💾에 불이 켜집니다.** 저장 전 내용도 껐다 켜거나 채팅방을 옮겼다 돌아와도 그대로 유지됩니다. 되돌아가고 싶으면 ← → 로 이전 내용을 봅니다.
- 💾 저장하면 그 프리셋을 열어둔 다른 채팅방도(고치는 중이 아니라면) 새 내용으로 바뀝니다.
- 팝업 맨 위의 체크로 탭 전체를 끄면 초록불이 흐려지고, 켜 둔 프리셋이 있어도 프롬프트에는 들어가지 않습니다.

## 확장 설정 패널

- 프롬프트는 **저장 버튼을 눌러야 반영**됩니다. 고치는 중인 탭에는 ●가 표시되고 저장 버튼에 불이 켜집니다. 되돌리기로 저장된 프롬프트로 돌아갈 수 있습니다. 지금 보고 있는 탭은 테두리와 색으로 구분됩니다.
- 삽입 위치(Depth)는 접이식 섹션에 한꺼번에 나열됩니다.
- "🧹 초기화 · 데이터 삭제" 섹션: 기본값 초기화(프롬프트·Depth만), 이 채팅방의 규칙/AU/캐릭터/줄거리/채팅 칸 삭제, 모든 채팅방 전체 데이터 삭제(확인 2번, 프리셋·프롬프트는 유지).

## 이전/현재 내용 토글 (←/→)
범위별로 "직전에 저장돼 있던 내용"을 한 칸 기억합니다. 팝업 맨 아래 오른쪽의 ←/→ 버튼을 누르면
지금 내용과 직전 내용이 서로 맞바뀝니다. 바로 옆의 지우개 버튼으로 지운 내용도 이 버튼으로 복원할 수 있습니다.

## 데이터 저장 위치
- `extension_settings["Direction-Manager-DB"]` 하위에 `global / au / chars / chats / presets` 구조로 저장됩니다.
- 규칙·AU 탭의 채팅방별 내용과 켜 둔 프리셋은 `globals / aus` 아래에 채팅 단위로 저장됩니다.
- 줄거리 두 칸은 `plotMains / plotNexts` 아래에 채팅 단위로 저장됩니다.
- 캐릭터 카드 자체에는 아무것도 쓰지 않습니다(오직 `extension_settings`).
- 설정 패널(`settings.html`)은 이 확장이 실제로 설치된 폴더에서 읽습니다. 폴더명이 `Direction-Manager-DB`가 아니어도 됩니다.

## 업데이트 시 참고 (v1.6)
- 예전 **캐릭터 프리셋은 지워지지 않고 AU 프리셋 목록으로 옮겨집니다.** 필요 없는 건 AU 탭에서 지우면 됩니다. 캐릭터 탭에 적어 둔 내용은 그대로 남습니다.
- 규칙(예전 전역) 탭을 쓰던 채팅방은 지금 열어 둔 프리셋 하나만 켜진 상태로 이어지므로, 프롬프트 내용이 달라지지 않습니다. 이제 ★ 프리셋은 삭제할 수 있고, 여러 개를 지정할 수 있습니다.
- 삽입 Depth가 이전 기본값(전역 2 / 캐릭터 5 / 큰 줄거리 3 / 작은 줄거리 1 / 채팅 0) 그대로였다면 새 기본값으로 바뀝니다. 직접 바꾼 값은 그대로 둡니다.
- AU 프롬프트와 Depth(기본 2)가 추가됩니다. 직접 고친 프롬프트는 그대로 둡니다.
- 기본값으로 되돌리려면 설정 패널의 "기본값으로 초기화"를 누르세요 (프롬프트도 함께 초기화됩니다).
